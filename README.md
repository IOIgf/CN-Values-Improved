# CN Values 改进版

CN Values 是基于 8values 源代码开发制作的娱乐性政治立场测试，以中国当下语境为背景编制测试题。本项目是对原项目的增强和完善版本。

> 原始项目：https://github.com/CNValues/cnvalues.github.io
> 原项目作者已停止维护，本版本在其基础上进行了大量改进。

## ✨ 改进内容（v2.0）

### 🎯 评价结果更准确
- **修复重大Bug**：原项目的环境维度（生态 vs 生产）在意识形态匹配算法中完全没有被使用，导致匹配结果偏差。现在四个维度（经济、政治、社会、环境）全部参与匹配计算
- **改进距离算法**：使用标准欧氏距离，权重分配更合理
- **增加匹配度百分比**：不再只告诉你"最接近哪个"，还显示匹配度百分比，让你了解吻合程度

### 📝 题目扩充（90题 → 168题）
- 四个主要维度都补充了大量新题目
- 原来的19个特殊特质（入关学、阴谋论、儒家、工业党等）每个只有1道题，结果不可靠，现在每个特殊特质都有3道题目，评价更准确
- 修复了原文件中部分题目存在的格式问题

### 🧠 更多意识形态类型（27种 → 43种）
新增了以下意识形态分类：
- 无政府原始主义
- 生态社会主义
- 委员会共产主义
- 毛主义
- 绿色政治
- 社群主义
- 宗教原教旨主义
- 新儒家
- 海盗党
- 加速主义
- 技术官僚主义
- 第三条道路
- 人道主义干预主义
- 中立/中间派
- 政治冷漠主义
- 中国特色社会主义

所有意识形态现在都包含完整的4个维度数据。

### 📊 新增雷达图可视化
- 使用纯Canvas绘制四维政治坐标雷达图，直观展示你的立场位置
- 无需引入额外图表库，加载速度快

### 🔍 显示多个相近结果
- 除了最匹配的意识形态，还会展示前5个其他接近的意识形态
- 每个结果都有匹配度进度条和百分比，让你了解自己在政治光谱上的位置

## 🧭 四个基本维度

本测试通过四个坐标轴来衡量你的政治立场：

- **经济轴**：平等（共产主义/社会主义）↔ 市场（资本主义/自由放任）
- **政治轴**：自由（无政府主义/自由意志主义）↔ 权威（威权主义/极权主义）
- **社会轴**：进步（变革/激进）↔ 传统（保守/反动）
- **环境轴**：生态（环保主义/深绿）↔ 生产（发展优先/生产主义）

此外还有19个特殊文化维度标签：入关学、阴谋论、一神论、儒家、工业党、毛粉、皇汉、解体论、民国派、女权主义、政治冷感、全盘西化、逆向民族主义、地方主义、社会达尔文主义、中国特色社会主义、海盗党、加速主义、社群主义。

## 🛠️ 本地运行

本项目是纯前端静态网站，直接用浏览器打开 `index.html` 即可使用，或者启动一个本地HTTP服务器：

```bash
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```
